# LanPartyGoDS photo removals

This is the public record of photos taken off the LanPartyGoDS group sites because somebody asked.

Each **issue** is one photo. It says which group, album and file it was, the reason category the person picked, and when it came down.

What you will **never** find here:

- the picture itself
- the name of the person who asked (that stays in a private log)
- any free-text note from the requester

How it works, in short:

1. A visitor signs in with GitHub on the removal form (to keep it from being abused) and picks the photo and a reason.
2. The photo disappears from the site immediately.
3. The Worker opens an issue here with the details above.
4. If a removal is mistaken or misused, the site owner can restore the photo. The issue then gets a comment and is closed as restored.

Labels: `removal` (every entry), `group:<name>`, `reason:<category>`, `restored`.

Want a photo down? Use the form on the album page ("Request removal"). Photos are shared freely and nobody should be in one they would rather not be.
